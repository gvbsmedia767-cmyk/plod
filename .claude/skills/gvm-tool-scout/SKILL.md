# GVM Tool Scout

## Trigger
Поиск новых или лучших рабочих инструментов, автоматизаций, навыков и моделей, сравнение замен и сборка проверенного production-стека.

## Process
1. Сформулируй задачу GVM, измеримый эффект и ограничения: Windows, GPU, данные клиентов, лицензия, бюджет.
2. Ищи первоисточники: авторский репозиторий, документация, release notes, model card, реальные ограничения. Не ограничивайся 1-2 знакомыми брендами.
3. Для каждого кандидата проверяй URL, назначение, дату активности, способ использования, Windows/Cloud/Mobile, доступность API, коммерческую лицензию, цену и разрешения.
4. Отдельно оценивай безопасность SKILL.md, скриптов установки и MCP-сервера: prompt injection, чтение env, отсылка файлов, удалённые POST, полномочия.
5. Сопоставляй минимум три реалистичных решения по качеству, времени внедрения, GPU-потреблению и себестоимости; не завышай баллы при отсутствии проверок.
6. Выбери один пилот на тестовых данных, сформируй протокол измерения качества, времени, результата, возможного отката.

## Output
Таблица: инструмент | проверенный URL | задача | источник факта | лицензия | стоимость | требования | риски | статус | пилот. Ни один кандидат не называется установленным без успешной проверки. При отсутствии веб-доступа явно указать это.
