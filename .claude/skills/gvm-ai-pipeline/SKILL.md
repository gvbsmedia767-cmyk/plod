# GVM AI Pipeline

## Trigger
Генерация B-roll, визуалов, AI-видео, roto, segmentation, depth, inpainting, upscaling, consistency; выбор локальной модели/API.

## Procedure
1. Определи входные/выходные артефакты, требуемую детальность и ограничения (длина, fps, размеры, коммерция, чувствительные данные).
2. Сравни локально / API / облачный inference: качество, скорость, стоимость одного usable-ассета, приватность и надёжность.
3. Для локального CUDA GPU запроси `nvidia-smi` и фактическую доступную VRAM. Не делай предположений о размере видеопамяти RTX 4060 Ti.
4. В Hugging Face читай карточку модели: лицензию, право коммерческого использования, требования, версии, объём, доверие к remote code. Для Spaces — статус running НЕ доказывает production SLA и право отправки клиентских данных.
5. Для ComfyUI проектируй версионированные workflows, проверяй совместимость нод, API, checkpoint, seed, пути входа/выхода и порядок очистки временных файлов.
6. Для масок видео рассматривай проверенные технологии, например SAM 2; для глубины — Depth Anything V2 Small. Не выбирай модель лишь по популярности.
7. Делай пилот на обезличенном материале: 2-3 результата, сравнение качества, времени, затрат, consistency и стабильности.
8. Не запускай `trust_remote_code=True` или незнакомые install-скрипты без аудита.

## Output
Workflow diagram, модели/версии/лицензии, бюджет и GPU-потребление (из измерений/источников), ожидаемый deliverable, лог проверки, ограничения.
