# ПЕРВОЕ ЗАДАНИЕ CLAUDE — GVM CREATIVE OS BOOTSTRAP

Ты работаешь в НОВОМ аккаунте Claude. Я пишу с Android-телефона, а основной рабочий компьютер — Windows 11. Моя цель — сформировать профессиональную систему GVM Creative OS, чтобы Claude мог автономно искать подходящие технологии и навыки, готовить монтаж, создавать motion/CGI-графику, программировать, проектировать интерфейсы и впоследствии исполнять задачи на моём компьютере. Ты не консультант, а исполнитель в пределах реально доступных инструментов.

Начни действовать прямо сейчас. Не требуй компьютера для работы, которую можно выполнить в мобильном чате и облачной среде. Не обещай фоновой работы, если для этого нет запущенной задачи. Не выдавай инструкцию по нажатию кнопки за реально изменённую настройку.

ФАЗА 0 — ДИАГНОСТИКА ДОСТУПОВ.
Проверь, что тебе фактически доступно: веб-поиск/research, создание файлов и запуск кода, Projects, Skills, Connectors, GitHub, облачные сессии Claude Code, а также подключённые сервисы. Отметь каждую позицию одним из статусов: доступно и проверено / требуется моё действие / недоступно или не проверено. Если внутренние настройки не читаются программно, прямо скажи и дай краткую точную навигацию, как включить функцию. Учитывай, что на новом аккаунте Dispatch может быть недоступен. Не спрашивай пароли и API-ключи в сообщениях.

A. Монтаж / DaVinci Resolve / Fusion / мульткамерность / транскрипты / субтитры / авто-монтаж / цвет / шумоподавление / рендер.
B. Code-driven motion и рекламная инфографика: Remotion, After Effects-совместимые методы экспорта, Lottie/Rive, SVG, Canvas, WebGL, Blender, титры, кинетическая типографика, прозрачные оверлеи.

D. AI-видео и изображения: ComfyUI, разметка объектов, ротоскопинг, SAM, depth, video tracking, super-resolution, consistency, локальные и облачные модели, inference providers, Hugging Face Spaces.

ФАЗА 2 — ПЕРСОНАЛЬНЫЕ SKILLS.
Если доступно создание файлов, создай независимые ZIP-пакеты Skills по официальному формату Agent Skills (у каждого своя папка и SKILL.md с name/description), чтобы можно было загрузить в Customize > Skills:
1. gvm-tool-scout — непрерывная исследовательская методика поиска и проверки технологий по запросу;
2. gvm-video-director — режиссура монтажа, narrative, камера, темп, b-roll, DaVinci;
3. gvm-motion-engineer — Remotion/Fusion/Blender, титры, VFX, preview/render;
4. gvm-design-director — визуальный язык, ретушь, брендинг, UI;
5. gvm-fullstack-engineer — архитектура, реализация, тесты, UX/E2E;
6. gvm-ai-pipeline — ComfyUI, API, Hugging Face, модели и бюджет;
7. gvm-audio-director — голос, музыка, чистка, сведение и контроль звучания;
8. gvm-release-qa — технический и визуальный финальный контроль.
Делай небольшие, специализированные, тестируемые Skills вместо одного гигантского. Проверь валидность структуры ZIP и покажи файлы для скачивания; если нет инструментов создания файлов, подготовь полное содержимое и укажи честно, что ZIP не создан. Не сообщай «установлено», пока не проверишь активацию в настройках аккаунта.

ФАЗА 3 — ПРОЕКТ И ПОДКЛЮЧЕНИЯ.
Если Project уже создан, используй его постоянные инструкции и знания; если нет — предложи имя `GVM Creative OS | Production & Engineering` и выдай компактные точные шаги для создания из телефона. Определи минимальный полезный набор подключений (в первую очередь GitHub и необходимые облачные ресурсы) с ограниченными правами. При доступности облачного Claude Code предложи проверяемый пилот в отдельном тестовом репозитории. Не создавай публичный репозиторий и не отправляй материалы клиентов без разрешения.

ФАЗА 4 — ТЕСТЫ РЕАЛЬНЫХ ЗАДАЧ.
Предложи и, если среда доступна, исполни минимум два маленьких теста: (а) 5–10-секундная кодовая анимация типографики с предпросмотром/рендером и (б) адаптивный дизайн-прототип с browser/UI-проверкой. Отдельно подготовь план безопасного подключения моего Windows/DaVinci без вмешательства в существующие проекты. Чётко разделяй «создан исходник», «запущен», «видел предпросмотр» и «получен конечный файл».
