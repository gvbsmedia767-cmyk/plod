# GVM Motion Kit

Фирменные моушн-шаблоны GVM. Каждый ролик описывается JSON-спецификацией и рендерится одной командой в MP4. Работает в облачной сессии Claude Code: видеокарта не нужна, WebGL идёт через swiftshader.

## Шаблоны

| Шаблон | Что делает | Параметры (`params`) |
|---|---|---|
| `glass` | Слова из жидкого стекла преломляют плёночный свет | `scenes: [{at, lines: [{text, size, y}]}]` |
| `swarm` | Световой рой собирается в фразу, взрывается и пересобирается во вторую | `first`, `second`: `[{text, size, y, weight?}]`; `formAt`, `burstAt`, `reformAt` |
| `flythrough` | Пролёт камеры по работам в скруглённых рамках, в финале логотип | `works: [{img, label}]`, `words: [...]`, `tagline`, `logo` |

Пояснения к параметрам:
- `size` — размер строки как доля ширины кадра. Слишком длинная строка сама ужимается до 90% ширины.
- `y` — центр строки как доля высоты кадра.
- `at` — секунда, с которой показывается сцена.
- Пути к картинкам в `works` указываются относительно `templates/`. Пример: `../assets/works/kit-clinic-poster.jpg`.

## Спецификация

```json
{
 "template": "glass",
 "width": 1080, "height": 1920, "duration": 5, "fps": 30,
 "params": { "scenes": [ {"at": 0, "lines": [{"text": "ТВОЯ", "size": 0.26, "y": 0.38}]} ] }
}
```

Форматы:
- `1080×1920` — Reels, Shorts, Stories;
- `1920×1080` — YouTube, сайт, заставка в монтаж;
- `1080×1350` — лента 4:5.

## Команды

```bash
cd gvm-creative-os/motion-kit
npm install                                     # один раз: three.js
node render.js specs/reels-glass-9x16.json --preview   # черновик: половина размера, 15 к/с, 0,5–2 мин
node render.js specs/reels-glass-9x16.json             # финал
```

Что появляется в `out/<имя>/`:
- `<имя>.mp4` — мастер для монтажа, H.264 CRF 17;
- `<имя>_mobile.mp4` — лёгкая версия до ~3 МБ, открывается на телефоне;
- `poster.jpg` — обложка;
- `contact.jpg` — 4 контрольных кадра для проверки.

Сколько рендерится финал 1080×1920 в облаке:
- `flythrough` — около 3–5 мин;
- `swarm` — около 4–6 мин;
- `glass` — около 15–20 мин, это самый тяжёлый шейдер.

Сначала всегда делайте `--preview`.

## Свои работы

Положите кадр или постер в `assets/works/`: JPG, длинная сторона до 900 px. Добавьте его в `works` спецификации. Сейчас там постеры с gvbsmedia.ru.

## Ограничения

- Фон непрозрачный. Для оверлея в DaVinci поверх видео нужна отдельная доработка: альфа-канал через PNG-последовательность.
- В рамках `flythrough` стоят стоп-кадры. Видео внутри рамок — следующий шаг, текстуры из MP4.
- Музыки нет. Звук добавляется при монтаже или в Remotion.
- Шрифты Unbounded, Onest и Martian Mono лежат в `assets/fonts`. Лицензия OFL, коммерческое использование разрешено.
