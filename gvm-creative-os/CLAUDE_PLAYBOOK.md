## 2. Мастер-сессия: какой вариант выбрать

- **Вложенные сессии на ПК** [со слов автора]: видят ваши skills, файлы, DaVinci. Останавливаются, когда ПК спит → включите *Settings → Claude Code → Keep computer awake while Claude works* и *Connect new sessions to Remote Control*, тогда всё ведётся с телефона.
- **Claude Code Projects в облаке** [со слов автора; beta, Pro/Max; ищите в сайдбаре или в *More*]: работают без ПК, общая память проекта, обзорная страница «готово / в работе / ждёт вас». Файлы клиентов уходят на серверы Anthropic — для закрытых материалов спрашивать согласие.
- **Облачная Мастер-сессия** (вариант из `MASTER_SESSION.md`) [подтверждено]: видит и облачные, и ПК-сессии (`list_sessions`), создаёт облачные под-сессии. Работает уже сейчас, без Projects.

Правило GVM: **материал на ПК → вложенные сессии на ПК; код/дизайн/долгие задачи → облако.** Мастер один — закреплённый, остальные чаты разложены по разделам (Sections) «Клиенты / Церковь / GVM Studio / R&D».

Вложенная сессия vs субагент [со слов автора]: под-сессия — настоящий чат, в него можно зайти и поправить курс; субагент — разовое поручение. Для дизайна и анимации, где нужны правки по ходу, — под-сессии.

## 3. Экономия лимитов

1. **Контекст-карточка** (Session rail → Context) [со слов автора]: skills, memory и MCP-коннекторы грузятся в каждый чат до первого сообщения. В этой сессии видно 15 коннекторов плагинов design/marketing, которые не подключаются (ошибка прокси 403), плюс ~150 инструментов Higgsfield [подтверждено]. Отключите то, чем не пользуетесь.
2. `/skill-doctor` — какие skills сколько стоят и как часто используются; `/doctor` — проверка настроек и CLAUDE.md [со слов автора].
3. `/advisor` — работать на дешёвой модели и звать сильную только на крупных решениях [со слов автора].
4. Вопросы по ходу длинной задачи — в side chat (`/btw`), а не в основной чат [со слов автора].
5. Prompt cache остывает примерно через час — длинную паузу лучше закрыть `/recap` в новом чате, чем продолжать огромный старый [со слов автора].

## 4. Полезное сразу

- `Ctrl+Alt+Space` — Claude из любого окна; `Ctrl+D` — голосовой ввод; `Esc Esc` — откат (`/rewind`); `Ctrl+/` — все сочетания [со слов автора].
- Split view: `Alt`+клик по чату — 2 чата рядом (Мастер + текущая под-сессия).
- **Mods** — надстройки интерфейса, делаются описанием [подтверждено: в облачной сессии есть skill `plugin-authoring`]. Кандидат для GVM: полоска «остаток лимита + состояние кэша + статус рендера».
- **AI-powered artifacts** (*Settings → Capabilities*) [со слов автора]: например, дашборд Metricool, которому клиент задаёт вопросы сам.
