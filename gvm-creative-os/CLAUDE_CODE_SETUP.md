# ПОДКЛЮЧЕНИЕ WINDOWS / CLAUDE CODE — ПЛАН НА ПОТОМ

Не требуется, чтобы начать исследование в Claude с телефона.

## При возвращении к ПК
1. Проверь тариф и доступность Claude Code / облачных сессий (https://claude.ai/code).
2. Подготовь отдельный тестовый Git-репозиторий (не клиентский проект); используй ветку экспериментов и резервные копии.
3. Проверь Windows 11, Node.js, Git, Python, ffmpeg/ffprobe, NVIDIA драйвер и nvidia-smi; не ставь пакеты наугад и не удаляй текущие окружения.
4. Изучи актуальную официальную установку Claude Code; для локальных задач используй изолированные разрешённые папки и инструменты. По желанию ознакомься с `/remote-control` и возможностями управления локальной Claude Code с телефона.
5. В первую очередь протестируй безопасный pipeline: анализ входного клипа -> разметка транскрипта -> автономная кодовая графика -> preview -> импорт оверлея в DaVinci на КОПИИ проекта -> рендер короткого фрагмента -> QA.
6. Только потом рассматривай интеграцию API DaVinci, ComfyUI и GVM Connect. Сначала `read-only`; затем тестовые записи в отдельную папку; только после проверки — клиентский проект с резервной копией.

## Пример (запускать только после изучения источника, не из мобильного чата)
- Официальный пример подключения Anthropic Skills в Claude Code: `/plugin marketplace add anthropics/skills`.
- Remotion Agent Skills (на ПК с совместимым Node.js): `npx skills add remotion-dev/skills` — проверить инструкцию и список skills до установки.
- Playwright MCP: см. https://github.com/microsoft/playwright-mcp — не выдавай широкие браузерные полномочия без нужды.

Нельзя считать локальный Windows подключённым только потому, что Claude вошёл на телефон в тот же аккаунт.
