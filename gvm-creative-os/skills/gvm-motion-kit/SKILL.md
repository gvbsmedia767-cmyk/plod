# GVM Motion Kit

## Когда использовать
Запросы вида «сделай заставку / рилс / интро / бренд-ролик GVM», «стеклом напиши …», «пролёт по нашим работам», «частицами собери слово …», «обложку и видео для Reels». Для клиентских роликов — только если клиент согласовал стиль GVM; иначе это бренд клиента (см. gvm-design-director).

## Порядок
1. Уточни из запроса: текст (коротко, ЗАГЛАВНЫМИ, ≤2 строки на сцену), формат (Reels 1080×1920 по умолчанию; YouTube/сайт 1920×1080; лента 1080×1350), длительность 5–8 с, шаблон:
   - `glass` — премиальная заставка, слово-удар;
   - `swarm` — эффектное появление фразы → логотип;
   - `flythrough` — шоурил/портфолио, нужны кадры работ.
2. Скопируй ближайшую спецификацию из `gvm-creative-os/motion-kit/specs/` в новый файл, поменяй текст/кадры. Кадры работ клади в `motion-kit/assets/works/` (JPG ≤900 px) — только материалы, которые владелец разрешил показывать.
3. `cd gvm-creative-os/motion-kit && npm install` (если нет node_modules), затем `node render.js specs/<имя>.json --preview`.
4. Посмотри `out/<имя>_preview/contact.jpg` через Read: текст читается, не обрезан краем, нет наложений слов. Исправь спецификацию и повтори превью — не больше 2 итераций.
5. Финальный рендер без `--preview`. Отдай пользователю `<имя>_mobile.mp4` (через SendUserFile, display render) и путь к мастеру `<имя>.mp4` для монтажа.
6. Если нужно, загрузи мастер в Google Drive (папка «GVM — выбор стиля» или указанная пользователем) — только по просьбе.

## Правила
- Текст по-русски, без опечаток; одно акцентное слово максимум.
- Не обещай прозрачный фон: шаблоны рендерят непрозрачный кадр.
- Время рендера `glass` 1080×1920 ≈ 15–20 мин — запускай в фоне и предупреди.
- Новые эффекты добавляй как новый шаблон в `templates/` с `window.GVM_PARAMS`, `window.ready`, `window.render(t)` — детерминированно по времени, без Math.random в render.
