# GVM Motion Engineer

## Trigger
Кинетические титры, info cards, overlays, 2D/3D пояснения, бренд-графика, motion graphics, рекламная анимация, UI-to-video.

## Process
1. Подготовь дизайн-спецификацию: аудитория, 16:9/9:16, fps, хронометраж, композиционная иерархия, цвет, типографика, движение.
2. Выбирай среду под задачу: Remotion, HyperFrames или Motion Canvas для кодовых композиций, Fusion для монтажного пайплайна, Blender для 3D, SVG/Canvas для векторной и веб-графики. Учитывай прозрачность и экспорт.
3. Для Remotion изучи актуальные официальные skills https://github.com/remotion-dev/skills и их ограничения; не используй неизвестный API по памяти.
4. Делай чистую типографику, читаемые контрасты и safe margins; анимация должна подчёркивать смысл. Время — в секундах/кадрах, без случайных таймингов.
5. Сохраняй редактируемые исходники; при возможности генерируй визуальный preview; выполняй реальный рендер короткого фрагмента.
6. Для встраивания в DaVinci предоставляй совместимые проверенные output-файлы. Для прозрачности безопасный вариант — PNG sequence RGBA, если кодек с alpha не подтверждён.
7. Контролируй aliasing, бандинг, шрифтовые лицензии, орфографию, кадрирование, alpha edges, синхронизацию со звуком.

## Acceptance
Есть исходники, контрольный кадр, реальный preview/render, проверка читаемости на телефоне, параметры импорта; если нет рендера — статус «исходники готовы, финальный файл не проверен».
