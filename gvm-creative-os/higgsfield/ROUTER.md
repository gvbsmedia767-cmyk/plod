# GVM × Higgsfield — маршрутизатор задач и цены

Проверено через Higgsfield MCP 2026-10-21. Аккаунт: тариф **Ultra**, баланс на момент проверки **3001 кредит**.
Все цены ниже получены вызовом `get_cost: true`: это бесплатная оценка, задача при этом не создаётся. Перед каждой реальной генерацией цену нужно перепроверить: тарифы меняются.

## 1. Главный принцип: дорогой результат без дорогих трат

1. **Код и монтаж стоят 0 кредитов.** Титры, инфографика, UI, счётчики, переходы, цвет, камера по готовому кадру, сборка делаются кодом: Higgsedit в песочнице Higgsfield, Remotion или Fusion на ПК. Генеративное видео нужно только для живого движения, которое кодом не сделать. Правило Katana: «never generate a graphic scene as video: models blur text and drift off the timing».
2. **Сначала дешёвые кадры, потом видео.** Утверждённый still (0.12–4 кр) становится стартовым кадром или референсом для видео. Так переделок видео (35–80 кр за 5 с) становится в разы меньше.
3. **Canary.** Сначала один самый сложный job семейства на финальных настройках. Остальные идут batch только после проверки canary.
4. **Разрешение по факту выдачи.** 720p хватает, если кадр в монтаже ≤720 px по короткой стороне, идёт в окне или сильно стилизован. 1080p нужен, если есть читаемое лицо при увеличении ≥1.3× (правило Katana §2.8).
5. **Multi-shot плейты Seedance.** Несколько планов в одном job: `Shot 1 (0-2s): …, Shot 2 (2-4s): …`. Тайминги в промпте задают порядок, а не точное время: закладывайте ×2 на каждый план.
6. **Один дубль на плейт.** Перегенерируется только упавший план, отдельным коротким job. «Хочу дубль получше» браком не считается.

## 4. Связка с ПК (GVM Connect, хост GVBSMEDIA)

- Рабочая папка: `E:\Для chat`. Там уже есть Remotion-проекты `GVM_Motion_Lab` V1–V4.
- Через Connect доступны: чтение файлов, ffprobe и превью, рендер ffmpeg (по одобрению), `reference_board` (мудборды Pinterest/Behance/Dribbble), `reference_outliers` (YouTube-выбросы).
- Коннектор DaVinci (`resolve.observe`, `resolve.workflow`) зарегистрирован, но в журнале Connect помечен **UNVERIFIED**: ни одного подтверждённого вызова ещё не было.
- Схема работы: Higgsfield генерирует плейты → готовые MP4 скачиваются на ПК → монтаж и цвет в DaVinci, графика кодом в Remotion или Higgsedit → QA.
